Action refusée par la base de données.

Les droits admin sont reconnus côté serveur à partir de ton adresse e-mail Clerk (marley.ebok@gmail.com). Si une action est refusée :

  1. Déconnecte-toi, puis reconnecte-toi via Google avec le compte marley.ebok@gmail.com.

  3. Si le problème persiste, vérifie que les variables d'environnement (DATABASE_URL, CLERK_SECRET_KEY) sont bien configurées sur Vercel.

🖼 Hébergement des affiches

Les affiches déposées avant la mise en place du stockage de fichiers sont enregistrées dans la base. Elles s'affichent normalement, mais alourdissent la base et ne peuvent pas servir d'aperçu au partage sur les réseaux. Cette action les dépose sur le stockage et les remplace par leur adresse.
